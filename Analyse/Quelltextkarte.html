Sternenschweif – Quelltextkarte

Rekonstruierter Quelltext von SCHWEIF.EXE (Das Schwarze Auge 2, Attic 1994). Borland C++ 3.1 baut daraus eine Datei, die Byte für Byte dem Original gleicht. Alle Module nach Spielbereich, mit Funktionen und den Fehlern, die schon im Original stecken.

Stand 19.10.2026. Fehler sind bewusst so nachgebaut, damit der Build bytegleich bleibt; Kandidaten für einen späteren Build mit Fehlerbehebung. „Bright-Eyes“ nennt die Entsprechung im Schicksalsklinge-Nachbau.
